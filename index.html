Vials

Add a vial

Any genotype makes a vial of flies to work with; nothing is added to a stock list. A slash separates the two homologues; semicolons separate chromosomes. Each allele goes to its own chromosome, so vg alone lands on 2. Case matters: b is black, B is Bar.
Anything the library does not know is carried as an invisible marker on the chromosome you wrote it on.
Balancers: FM7a, CyO, SM5, SM6a, TM3,Sb, TM3,Ser, TM6, TM6B, TM6C, TM2, MKRS.

Alleles

Map positions come from you, not from the app: look the gene up on FlyBase and enter its genetic map position. Mothers recombine, fathers do not, and a balancer suppresses the whole chromosome it is on.

Fly list

Click a line to put that stock in a vial. The list that ships with the app is the standard balancers and markers; load your own to search your lab's flies instead. Nothing is uploaded — the file is read here in the browser.

What the file should look like

A .csv or .tsv with one stock per row and a header row. Only Genotype is required; the rest are used if they are there, in any order, and any other columns are ignored.

  • Genotype — required — w; cnn[f04547]/CyO
  • Stock # — your number for it — JR417
  • Description — free text — from Bloomington
  • Project — free text, for searching — centriole
  • In stock — yes/no, y/n, 1/0

So a whole file can be four lines:

Stock #,Genotype,Description,In stock
JR417,"w; cnn[f04547]/CyO",from Bloomington,yes
JR418,"w; +; Sas-6/TM6B",,yes
JR419,"w; Sco/CyO; Dr/TM6C",double balancer,no

Commas inside a genotype are fine as long as the cell is quoted, which Excel does for you. Headers are matched loosely, so stock number, Held? and notes are all understood; a file with no header row still works if one column is clearly the genotypes. With no in-stock column every row counts as held. An .xlsx cannot be read here — in Excel use File → Save As → CSV, or run data/build_stocks.py.

Balancer editors

What each balancer carries

A balancer's markers are welded to it — the inversions stop any crossover product being recovered, so they can never be separated by recombination. MKRS is the exception: it carries no inversions, so it is listed here but does not suppress.
Marker sets differ between labs. Changes apply to the flies already on the bench. Anything you change here, and any of your own alleles you make visible, is remembered in this browser — save the file to keep it beside the app.
